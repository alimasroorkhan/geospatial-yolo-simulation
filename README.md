# Leaflet Satellite Drone Ops Terminal

A lightweight browser-based UAV simulation using Leaflet satellite imagery.

## Features

- Lightweight Leaflet map, not Cesium
- Satellite imagery by default
- UAV shown as a rotating arrow
- Keyboard movement controls
- Altitude up/down controls
- Always-on downward camera view on the right side
- Capture button saves the current camera view as a JPG in the `captures` folder
- Local tile proxy and cache through Python backend
- Military-style HUD interface
- YOLO-ready folder structure for later integration
- Mission Scan workflow with sector grid planning, lawn-mower traversal, YOLO inference, and reports

## Controls

| Key | Action |
|---|---|
| W | Move forward |
| S | Move backward |
| A | Strafe left |
| D | Strafe right |
| Q | Yaw left |
| E | Yaw right |
| R | Altitude up |
| F | Altitude down |
| Shift | Boost speed |
| H | Toggle hold mode |
| Space | Capture camera JPG |

## Run in PowerShell

Open PowerShell inside this project folder and run:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn server.main:app --reload --host 127.0.0.1 --port 8003
```

Then open:

```text
http://127.0.0.1:8003
```

## Where screenshots are saved

When you press **CAPTURE JPG** or press **Space**, the camera image is saved here:

```text
captures/
```

The app also shows a link to the saved JPG.

## Project structure

```text
backend/            FastAPI application code
frontend/static/    Browser UI, CSS, and JavaScript served at /static
models/             YOLO model weights
captures/           Saved UAV camera captures and live previews
cache/tile_cache/   Cached satellite imagery tiles
debug/captures/     Latest debug frames and prediction outputs
data/samples/       Local sample images
reports/            Project report and presentation artifacts
server/             Compatibility entry point for server.main:app
```

Mission reports are saved in:

```text
reports/missions/
captures/missions/
```

## Notes

This is a simulation/prototype. It uses satellite tile imagery and a browser-based UAV control model. The saved camera image is generated by the Python backend from the same satellite tiles used in the camera view.


## YOLO model integration

1. Place your trained Ultralytics YOLO model here:

```text
models/best.pt
```

2. Install YOLO support:

```powershell
.\.venv\Scripts\python.exe -m pip install ultralytics
```

3. Restart the server. The `/api/capture` endpoint will run YOLO on the JPG camera capture and draw detection boxes on the saved image.

Saved captures appear in:

```text
captures/
```
