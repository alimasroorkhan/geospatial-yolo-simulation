PROJECT OVERVIEW

AI-based satellite imagery detection system for identifying aircraft, airport areas, and storage tanks using a YOLO OBB model.

DATASET AND MODEL

The detector uses YOLOv8 OBB with Oriented Bounding Boxes because satellite objects can appear rotated in aerial views.

airplane airport storage_tank

MODEL PERFORMANCE

Precision 87.0%
Recall 87.1%
mAP50 90.3%
mAP50-95 68.3%
Class Precision Recall mAP50 mAP50-95
Airplane 97.5% 96.8% 98.2% 87.7%
Airport 71.5% 70.9% 76.5% 38.1%
Storage Tank 92.2% 93.6% 96.2% 79.3%

Since this is an object detection system, the model was evaluated using precision, recall, mAP50 and mAP50-95 rather than simple classification accuracy. The model performed strongest on airplane and storage tank detection, while airport detection was weaker due to fewer examples and the larger, more complex nature of airport regions.

APPLICATION PURPOSE

The interface connects simulated UAV movement, satellite tile capture, and live YOLO OBB inference so detections can be reviewed directly from the drone camera workflow.
